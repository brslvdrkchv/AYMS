# AYMS Conf 2026 — Annual Young Medical Scientists' Conference

Офіційний вебсайт щорічної конференції молодих вчених **Annual Young Medical Scientists’ Conference 2026 (AYMS Conf 2026)**.

Захід присвячений:
- **185-річчю** Національного медичного університету імені О. О. Богомольця
- **145-річчю** Студентського наукового товариства імені О. А. Киселя
- **90-річчю** першої студентської конференції (1936)

**Дати проведення:** 26–27 листопада 2026 року, Київ  
**Формат:** Змішаний (офлайн в аудиторіях НМУ + онлайн-платформа)

## Особливості сайту
- **Адаптивна верстка:** Повна підтримка всіх типів пристроїв — від мобільних телефонів (320px+) до великих десктопних моніторів (Full HD / 4K).
- **Дизайн:** Академічний сай-фай мінімалізм, фірмові кольори, неонові та космічні свічення, 3D-стрічки та скляні картки (glassmorphism).
- **Інтерактивність:**
  - Плавна навігація між розділами (ScrollSpy, sticky header).
  - Мобільне меню (hamburger toggle).
  - Модальні вікна з регламентом: вимоги до оформлення тез, зразок оформлення роботи, вимоги до виступу й слайдів.
- **Швидкість та автономність:** Чистий HTML5, ванільний CSS3 та JavaScript без зовнішніх важких бібліотек чи фреймворків.

## Структура проекту
```
AYMS/
├── index.html        # Головна сторінка сайту
├── style.css         # Стилі сайту з повною адаптивною версткою
├── script.js         # Інтерактивна логіка (меню, модальні вікна, навігація)
├── fonts/            # Шрифти (FalconSportOne, Montserrat)
└── images/           # Графічні матеріали (векторні SVG, логотипи, 3D ассети)
```
